# Zeus 0.9.8.0

A thunder client for Minecraft **1.21.11** (Fabric, Java 21): about 176 modules, a Zeus main menu, an intro film, a full-screen storm panel, world scanners, waypoint tools, movement assistance, a schematic builder and a local website with a live control center. Press **Z** in a world (or type `/zeus`) to open the panel.

This README is the single document for the whole project. It replaces the 49 separate release-note, build-status and review files that used to sit next to it; everything they said is kept below (see "Version history" and "Third-party attribution").

**Client-side behaviour and server limits.** Zeus draws overlays and controls your local client. Multiplayer servers are authoritative for movement, combat and blocks, and can correct or punish what Zeus does. The world scanners only read chunk data that Minecraft has already delivered to your client; nothing here can reveal unloaded terrain, server-hidden blocks or players the server never sent. Check the rules of every server before you use a module on it (see "What a server accepts").

**Not run in real Minecraft.** Every version of Zeus so far, 0.9.7.0 included, was compiled and logic-tested against hand-written stand-ins for the game's classes, never launched in a real Minecraft. Read "Honest limits" before you rely on anything.

## Setup, step by step

1. Install **Java 21**. Check with `java -version` in a terminal; it must say 21 or higher.
2. Install the **Fabric Loader** for Minecraft **1.21.11** (from fabricmc.net) and start that profile once, so the `mods` folder exists.
3. Download **Fabric API 0.141.6+1.21.11** (or newer for 1.21.11) and put its jar in the `mods` folder (`.minecraft/mods`).
4. Unzip this project. The archive has exactly one top-level folder, `zeus/`. In that folder run `gradlew.bat build --no-daemon --console=plain` (Windows, or double-click `build.bat`) or `./gradlew build` (Mac / Linux). The first build downloads Gradle 0.9.5.1, Minecraft and the mappings, so give it a few minutes and an internet connection.
5. Copy `build/libs/zeus-0.9.8.0.jar` (not the `-sources` one) into the same `mods` folder.
6. Start the game with the Fabric 1.21.11 profile. When loading ends, the **intro film** plays (any key or click skips it) and then the **Zeus main menu** appears. The first time you enter a world a short animated tour shows every category; replay it with `/zeus tutorial`.
7. In a world press **Z** to open the panel. Click a module row to open its settings, click its switch to turn it on, click the **None** chip and press a key to give it a key. **Panic** (bottom right) switches everything off.
8. If something looks wrong: open **Zeus Customs** from the menu (or the panel in a world), go to the **Panel** page and check **Zeus main menu**, **Intro film at start-up** and **Intro animation**. The **Classic menu** link in the corner of the menu goes back to the game's own title screen.
9. If the build fails, send the first red lines of the Gradle output. If a module does nothing in game, send its Status text and the "Zeus" lines of `logs/latest.log`.

Settings save to `config/zeus.json`. Waypoints are in `config/zeus-waypoints.json`. Schematics go in `config/zeus/schematics` (Litematica's own `schematics` folder is scanned too).

## What is new in 0.9.8.0

- **Seven new modules.** Target Strafe (Combat) circles the player or mob you fight at a set distance. Auto Farm (World) breaks ripe crops, nether wart, pumpkins and melons around you and plants the crops again. Chest Stealer (Tools) takes the contents of an open chest, barrel, shulker box or hopper, all of it or only valuables. Inventory Cleaner (Player) throws junk out of your inventory. Loot Walker (World) walks to the nearest dropped item. Entity Speed (Movement) makes the horse, boat or other mount you ride go faster. Ore Compass (HUD & Info) is a small panel listing the nearest ore of each kind with distance, direction and height. It only reads blocks the game has been sent.
- **Kill Aura** can attack players (friends are always spared) and can pick the target with the lowest health instead of the nearest.
- **No more single-player locks.** MultiAura, Tunnel Miner, Tree Bot and the Schematic Builder's auto-place used to refuse to run on a server. They now work everywhere, and breaking goes through the game's own hold-to-break so a server sees ordinary digging. The setting "Auto-place (single-player)" is now "Auto-place".
- **Knife gallery.** In the Butterfly & Karambit settings, "Open the knife gallery" opens a menu with every knife on the left and every finish of the chosen knife on the right. Each picture is drawn by the same code that draws the knife in your hand. A click changes the setting at once.
- **Inspect.** Every knife has its own Inspect trick (six styles, mirrored and doubled across the twenty knives), in the trick list of the butterfly and of the karambit and the other knives.
- **Website.** A Knife preview page shows every knife in every finish, using pictures rendered by the mod's own knife code, and a Performance monitor page shows a gauge and a bar for every module's estimated cost. The site text was rewritten to read plainly.
- **What I did not add.** Amethyst Bypass and Netherite Finder. They exist to get around a server's anti-xray, and that is a line I keep.
- **Honest note:** none of this has been run in real Minecraft. The new modules compile against stand-ins and pass a smoke test that switches each one on and runs ticks and HUD draws, which proves they do not crash on the stand-ins, not that they behave right on a real server. Target Strafe, Entity Speed and Loot Walker move you by setting your own velocity, which a server with movement checks can object to.

## What is new in 0.9.7.0

- **What each module costs, right in the list.** Every module row in the panel now shows its measured cost (a share of Zeus's own time per frame, green, amber or red) next to its switch, so you can see what eats frames without opening the Performance Monitor. Switch it off in the UI settings (Show what each costs). The Module list on your HUD can show the same figure (Interface > Module list > Show what each costs). The website's Features page marks the heaviest modules with a Heavy badge.
- **Performance monitor on the website.** A new page (More menu, /monitor) shows a gauge, a bar for every module and a split by game tick, screen drawing, world drawing and scanning. Pick a playstyle or tick modules and it adds up their estimated cost. It is an estimate worked out from what each module does every frame, not a measurement. The site text was also rewritten to read plainly.
- **Performance Guard.** A new module that switches the costliest ESPs and scanners off by itself when your FPS stays under a limit you set, waits, and switches them back on once the frame rate has recovered. You choose the limit, how many it switches off at a time, whether it only touches scanners or everything, and it tells you in chat what it did. It will not touch anything you switched off yourself.
- **`/zeus website`.** The website command is now just `/zeus website` (with `stop` and `status`), and its chat message is a designed card: a header, the address as a clickable line, buttons to open or copy the link, and a short note on what the page can do.
- **Keybinds screen.** `/zeus keybinds` (or the Keybinds module) opens one list of every module with its key. Click a key box, press a key, done; Backspace or right click clears it; keys that two modules share are marked. The keys are the same ones Options > Controls shows.
- **Update checker.** When you join a server, Zeus asks the address you set (a small `version.json` that `tools/build_website.py` writes next to your site) whether a newer Zeus exists. If so you get a chat line and a pop notification at the top of the screen for about five seconds. It is off until you set the address.
- **Death marker.** When you die, Zeus remembers the place and shows a marker with the distance, so you can find your things. It lives in memory only and is cleared when you leave the game.
- **Staff Live.** The channel list is now editable in the menu (add a name, pick YouTube, TikTok or Twitch, remove with one click) and Twitch is supported. The check is a best-effort page read, so a channel may show as unknown.
- **Knives.** Every trick now blends into the next without a jump (the worst frame-to-frame change in the measured tricks fell by about two thirds), flicks start softer and snaps end softer. There are eighteen new knives modelled on CS2 shapes: Bayonet, M9 Bayonet, Huntsman, Flip, Gut, Falchion, Bowie, Navaja, Stiletto, Talon, Ursus, Classic, Paracord, Survival, Nomad, Skeleton, Kukri and Shadow Daggers. Each has its own blade, guard and handle, and twelve finishes (Stainless, Blue steel, Fade, Slaughter, Crimson web, Doppler, Case hardened, Night, Forest, Gamma Doppler, Gold, Damascus, plus Rainbow). They use the karambit's tricks. The designs are drawn from scratch, the motion is mine, and nothing was copied from another client.
- **The website.** Features page weight badges, new help answers, a timeline entry and the documentation for all of the above.
- **The jar.** The news scroll picture on the main menu now uses a 256-colour palette. On its parchment it looks the same, and the file went from about 5.6 MB to 0.8 MB. No feature was removed. By my measurement of the resources and the compiled classes the jar should come to about 18 to 19 MB, under your 20 MB goal, but I cannot build the real jar here, so check `build/libs/zeus-0.9.8.0.jar`.

## What is new in 0.9.6.0

### Performance first
- **Idle modules cost nothing.** The tick and draw loops only walk the modules that are switched on, and the list is rebuilt only when a module is switched on or off. Heavy scanners and ESPs are marked light: in Light mode they run every second tick and in Minimal mode every fourth.
- **Game mode (Interface): Balanced, Light, Minimal.** Light is the default. It flattens rounded boxes, drops glows and shadows, skips outline halos and uses fewer pieces per box. **Auto-lighten** steps one level lighter when the frame rate falls under 45 and two levels under 30, and back when it recovers.
- **Cached lists.** The Module List and Info HUD rebuild their rows a few times a second instead of every frame; the ESP helpers no longer allocate while drawing.
- **Performance page and Performance Monitor.** The page (Interface) shows the current mode and has buttons to pick one, to show what costs the most, and to switch off the three costliest modules. The Monitor (Panels) is a small HUD list of the modules that take the most of the game thread, with percentages. It only measures while it is on, so it costs nothing when it is off.
- **Honest note:** none of this could be measured here (see "Honest limits"). Use the Monitor to see what costs the most on your computer.

### The module windows
Each category window is smaller (narrower, four or five rows before it scrolls). **Recently used** is gone from the windows and only appears in the panel layout.

### New modules
- **Crystal PvP Bot and Sword PvP Bot (Combat).** Fighting bots. The Sword Bot closes in, strafes, jumps and hits on the way down for critical hits, taps forward off between hits, keeps out of reach while the swing recharges, eats golden apples, mends armour with experience bottles when nobody is close, refills the hotbar from the inventory and throws an ender pearl to close a gap. The Crystal Bot keeps the right distance, knocks the enemy up with a sword, guards you with Surround and steers Crystal Aura and Anchor Aura. Both switch the helper modules they need on and put them back. They never target friends.
- **Crystal Optimizer, Spear Swap (with a key for the lunge), FastXP, Fast Use (Combat/Utility), Click TP, No Jump Delay (Movement), Anti Ghost Block, Anti Trap, Auto Reconnect and Skin Change.**
- **AH Sniper** inside Auction House Tweaks: off by default, rules like `item=maxprice`, a spending limit, a purchase limit and pauses; it stops itself at the limits.
- **Staff Live:** alerts when a channel in your list goes live on YouTube or TikTok (a toast, a chat line, a chime and a HUD box). It starts with a list of channels you should edit.
- **Atmosphere:** a night sky with stars and an aurora painted on your screen, plus a clock lock and clear weather. It is an overlay, not a replaced sky.
- **Discord Rich Presence:** shows what you are playing on your Discord profile. It needs the Discord app and an Application ID from discord.com/developers.

### Not built
- **Amethyst Bypass and Netherite Finder.** Both work by seeing through a server's anti-xray, which Zeus does not do. Amethyst ESP, Block ESP and X-Ray show blocks the server actually sent.

### Versions
Every version number now starts with 0 (0.9.6.0, 0.9.5.0, ... 0.3.0), including the update timeline and the news scroll in the menu.

## What is new in 0.9.5.0

### Boat NoClip and Boat Fly, rewritten
Both now work with boats and rafts (including chest versions) and use the vehicle you are riding. Boat NoClip stops the boat being pushed out of blocks, can ignore the server's position corrections (a new setting) and no longer fights Boat Fly. Not tested on a real server.

### A tidier module list in game
Category windows are smaller, scroll inside once they pass eight rows, and a **Tidy** button packs them again. Window sizes are remembered.

### The website, as a published site
The site no longer describes itself as a page from your computer. It has a rebuilt header (five main pages plus a **More** menu), opening animations and a different background for every page, a small thunder cursor, an animated Z on the home page, a floating **Ask the helper** button, and an **Is Zeus safe?** dialog that points to the GitHub page for people who prefer not to download from the site. The control center still works the same way, from the link `/zeus website` prints.
- **Motion** has a Full / Calm switch in the footer. Full is the default and is no longer tied to the system's reduced-motion setting (that setting used to switch the typing animation off for everyone who had it enabled).
- **Helper:** it now shows a thinking indicator and types its answer, gives a differently worded answer when you repeat a question, and understands many more phrasings.
- **Build a config:** answer yes or no questions, or pick a playstyle, and get a pack of modules with the reason for each, a ban-risk meter and warnings; cheats-off, single-player and low-end answers filter the pack. Download `zeus.json`, copy `/zeus on` commands or save it to your profile.
- **Administration:** one administrator account (no email) can edit page text, links, a banner, the FAQ and the update timeline, and read the helper log. Changes are a browser-local draft that is exported as `overrides.json` and published with the site (`tools/site/overrides.json`, or `build_website.py --overrides <file>`). The sign-in is checked in the browser against a salted PBKDF2 hash, which keeps casual visitors out but is not server-side security. The credentials are not stored anywhere in the project.

### Website
- **Source code page** (`/source`): every file of the release in a tree with a filter and language chips, a viewer with line numbers and colouring, Copy / Raw / Download, and a GitHub repository button that says "coming in a future update" until you give the build a link (`--github https://github.com/you/zeus`). The page is filled by `tools/make_source_manifest.py` (see the release checklist below) and marks the files that changed since the previous release.
- **Profile page** (`/account`): create a profile, sign in with email and password, saved modules, configs, helper history, export/import. **It is not an online account**: there is no Zeus server, so the profile lives only in the browser, passwords are stored as salted PBKDF2 hashes and cannot be recovered, and the Google / Discord / GitHub buttons are disabled until a server exists.
- **Build a config** (`/config`): eight playstyles, an editable module list, and a `zeus.json` download (modules switched on at launch) or a list of `/zeus on` commands. Share codes are not offered because Zeus ignores on/off states inside share codes on purpose.
- **Troubleshooter** (`/troubleshoot`): yes/no wizard that ends at the right FAQ answer and the lines to look for in `latest.log`.

- **Helper**: a thinking and typing animation of one to three seconds that follows the answer's length, and a **Did that help?** button. Answers and unanswered questions are kept in the browser only and shown on the profile page.
- **Update timeline** entries link to the modules they added or changed and list the settings that changed; the module drawer shows which releases touched it.
- More motion (press ripples, tilt on cards, softer page changes) that the Full / Calm switch in the website footer turns down.

### Release checklist (every update)
1. Raise the version in `Zeus.VERSION`, `fabric.mod.json`, `gradle.properties` and `defaults.version` in `src/main/resources/assets/zeus/web/site.json`.
2. Add the release to `tools/site/timeline_data.py` (`TIMELINE` and `EXTRA` with the modules and settings it touched) and any new questions to `tools/site/help_*.py`.
3. Refresh `features.json` from the game's module list (`FeatureCatalog.json()`, also served at `/api/features` by the in-game site), then run `python3 tools/site/features_extra.py <web folder>` and `python3 tools/site/gen_site_data.py <web folder>`.
4. **Last step before building: `python3 tools/make_source_manifest.py`.** It copies the current source into the website's Source code page and marks what changed since the previous release (it compares with the bundle already in the folder, so keep that folder between releases). `tools/build_website.py` refuses to build if the bundle is for another version.
5. Build the jar, then `python3 tools/build_website.py --url ... --jar build/libs/zeus-<version>.jar --github <repo link> --out website`.

## What is new in 0.9.2.0

- **Floating panel** (drag it by its title): the widget list with on/off switches (so a switched-off widget can be turned on and placed), and an inspector for exact position, scale, opacity and accent colour.

Smooth page transitions and scroll animations, an animated Z emblem (a halo that breathes, a light sweep clipped to the emblem's own shape, a one-time shock ring, a soft 3D tilt that follows the cursor and drifting embers), a letter-by-letter wordmark in the new display font (Exo 2, SIL Open Font License), a sliding navigation indicator, card spotlights that follow the pointer, and a layout that works on phones. - **Help page** (button at the top right of every page): a guide for every part of the client (getting started, the panel, each module category, the HUD editor, the website, servers and safety, troubleshooting), a searchable FAQ of 80+ questions, and **the Zeus Helper**.
- **The Zeus Helper** is a small assistant that answers questions about Zeus and the website: install, any of the modules (including the typo-tolerant "what does kill arua do", "how do I bind fly to a key", "can it get me banned"), the HUD editor, the website, safety, privacy, bans, troubleshooting and the update history. It follows up ("and its settings?"), splits two questions in one message, and says so when it does not know. **It is not an AI model.** It is a search engine plus rules over the site's own texts, runs entirely in the browser, and nothing you type is sent anywhere. Click a module on the Features page to ask about it.
- **Update timeline** on the Information page, from the first version to today, newest first.
- **Clean addresses** (`/help`, `/features`...) instead of `#/help`. Old `#/page` links still work.

### Publish it on your own domain
`python3 tools/build_website.py --url https://zeus.example.com --download <link> --discord <invite> --jar build/libs/zeus-0.9.8.0.jar --out website` writes a ready-to-upload folder: a real page for every address with its own title, description and canonical link, `404.html`, `robots.txt`, `sitemap.xml`, security headers (`_headers`, `vercel.json`, nginx, Caddy and Apache examples), a `CNAME` for GitHub Pages, the jar's SHA-256 on the Download page, and `DEPLOY.md` with the steps for Cloudflare Pages, Netlify, GitHub Pages, Vercel or your own server. The public site never touches anyone's game: its Settings page only explains that the control center runs inside Minecraft. It must be served from the root of a domain or subdomain.

### Lighter client
The module search used to score every module against your text on every drawn frame. ## What Zeus deliberately does not do

These were left out on purpose, either because they work by attacking or evading server protections or because they would be unsafe or misleading:
- **Fake Lag packet holding.** Zeus has a Fake Lag *Monitor* (measured ping, average, jitter; the simulated value is display-only). It never holds, delays or spoofs packets.
- **Player Bypass.**
- **Block Entity Debug leak exploitation**, and **anti-xray bypasses** for Storage and Amethyst ESP. Zeus's Storage ESP and Amethyst Finder only show blocks the server actually sent.
- Server-specific shop and purchase automation, auto-buying, junk selling, disconnect policies and anti-cheat related behaviour. Since 0.9.6.0 the AH Sniper in Auction House Tweaks can buy by itself, but only when you arm it, only for the items and prices you typed, and only up to its spending and purchase limits.

**A short caution.** Many of the modules above (aimbots, triggerbots, flight, speed, Reach, Auto Clicker, Boat Fly on multiplayer, staff and vanish detection) are against the rules of most multiplayer servers and are noticed by anti-cheats. A ban is the server's call. Use them in your own worlds or where the rules explicitly allow it.

### 0.4.5.2 — base hunting, with what the other clients do

I looked at how the well-known base hunters work: Meteor's Stash Finder and Stash Hunter, the Trouser-Streak Base Finder, and Wurst's Base Finder. They mostly use a handful of ideas, and 0.4.5.2 now uses every one of them that works from what your own game holds:

- **Many kinds of player-made blocks (new).** Wurst flags every block that is not natural. Zeus now counts how many *different kinds* of player-made blocks a chunk holds (doors, planks, glass, signs, ladders, fences, beds, furnaces, torches, wool, concrete, bricks and so on, each colour counted once). Nature almost never makes four kinds in one chunk outside a village, so 4, 6, 7, 9 and 13 kinds add more and more evidence. A cabin with no chest at all is now caught.
- **Storage and workstations** (Stash Finder): kept, and scored per chunk, as in 0.4.5.1.
- **Ender pearls parked in a chunk** (Trouser-Streak entity checks): a stasis chamber. Strong evidence.
- **Name-tagged mobs**, **villagers outside a village** (a trading hall) and **big animal herds** (an animal pen, 9 or more of one kind in a chunk).

### 0.4.5.1 — small bases are found now

You built a test base and Suspicious Chunks missed it. That was a real flaw, not bad luck, and it had four causes:
1. **The score was too strict for small bases.** A hut with a bed, a couple of chests, a furnace and a crafting table scored about 46 %, but Medium needed 64 %. Outside a natural structure those blocks can only have been placed by a player, so they now count fully: a bed, storage and workstations each add evidence and the three together add more. The same hut now scores about 99 %, a bed with one chest about 77 %, and one lonely chest stays low. Inside a village or mineshaft they still count for little, so villages are not flagged.
2. **A rule demanded "two blocks no structure places"** before a chunk could be flagged. Beds, furnaces and crafting tables did not count towards it. That rule is gone; the judge decides.
3. **Fences, rails and farmland on the surface were being read as a mineshaft or a village**, which then hid the base. Mineshafts, strongholds, ancient cities, trial chambers and dungeons now count only when their blocks are mostly underground, and a mineshaft needs more blocks (18 instead of 10).
4. **Base Finder ignored finds smaller than two chunks.** The setting is now *Smallest find size* and starts at 1.

Also new: **Sensitivity: Very high** (flags anything a player could have placed), and an Info box on the card, **The chunk you are in**, that says how sure Zeus is about the chunk under your feet, what it found there (beds, storage, workstations...), what it needs, and whether that chunk looks like a natural structure. If a base is still missed, stand in it and send me that box.

Limits: a bed and a chest in the open can also be a lone traveller's camp, so at High and Very high expect a few small camps flagged. A one-chunk find is only as good as the blocks in it, and chunks your game has not loaded are not scanned.

### 0.4.4.0 — the smarter one

**Why Brute-force X-Ray against Paper is still not here.** Paper's anti-xray swaps hidden ores for fake blocks **on the server, before the data is sent**. The real ore is not in your game, so there is nothing to display. The only way past it is to make the server tell you things you are not supposed to learn (probing it with block updates, digging or timing tricks), and that is attacking the server, not a client setting. Zeus keeps to what your game already holds. X-Ray, Block ESP and the finders show every real block the server sends (singleplayer and servers without anti-xray work fully).

**The base brain (Suspicious Chunks and Base Finder)**
- Every chunk is now **judged**, not just counted. The scanner turns a chunk into evidence (blocks only players place, bed + storage, workstations, redstone machines, valuables, lit rooms underground, a mix of block kinds, item frames) and subtracts what nature explains (villages, mineshafts, strongholds and other generated structures, more strictly in the Nether). The result is a **confidence in percent**, a **type** (Base, Storage room, Farm / machine, Tunnels / mine, Build, Natural structure) and the **reasons**, shown on the map and in the world label.
- **One kind of clue alone never flags a chunk.** A pile of chests or beds with nothing else is capped.
- **Hubs and crowded servers are judged harder.** If a large part of the surrounding area looks built (a spawn, a hub), only the clearest finds count. Zeus also learns how built-up each server normally is (see Zeus Brain) and raises the cut-off on busy servers.
- **Neighbouring finds are merged**, so a base spread over several chunks is one find with a slightly higher confidence.
- **Only the top of a flagged chunk is outlined** (a frame at the surface, not the whole column). *Outline* can still be switched to the full chunk.
- **Smaller, optional map.** *Map detail* (Full, Compact, Tiny), *Map size* and *Tile size* are settings for both Suspicious Chunks and Base Finder, so the map can be as small as you like or off.
- **Raid check.** Zeus remembers every base it flagged (`config/zeus-bases.json`, per server) together with the key blocks it saw (storage, beds, workstations, hoppers). When you come back and **the chunk is loaded and those blocks are gone or the chunk is torn up**, the base is marked **Raided**; a few missing blocks mark it **Damaged**; if it is intact it says when it was last seen intact. **Limits:** it can only judge chunks that are loaded in your game right now, a base that was never seen is not in the list, and **emptying your own chests or taking your own base down looks the same as a raid**. Treat it as a hint.

**Zeus Brain (Utility, on by default).** It watches the frame rate and **slows the scanners down when your game lags** (down to a floor you set), learns how built-up each server normally is, and keeps that in `config/zeus-brain.json`. Its Info box says what it currently understands (dimension, server, frame rate, how many chunks it can afford to scan).

**Customisation.** Every ESP built on the shared look now has **Colour** (a list of colours), **Opacity**, **Label size** and **Tracer width**. The Staff HUD has **Size**, **Background**, **Accent** and a row limit. Storage ESP and the other block finders have a **Where** choice (Everything, Surface, Below the surface, Deep (20+ below), Above the surface) with a *Surface band* and height limits, so **Storage ESP can show only the surface, only below it, or everything**. It uses the real ground height at each spot; in the Nether and the End there is no ground, so everything counts there.

**Cave ESP v2.** Rebuilt: it only counts open space that is **mostly empty with ground above it** (*How open*, *Rock above*, no sky overhead, in your loaded chunks), joins touching cells into **caves** and drops small pockets (*Smallest cave*), draws boxes on the edge cells and a size tag on the big ones, and colours by depth. Mineshafts, big rooms you dug yourself and ravines still look like caves, so it says "open space" and not more.

**Butterfly Knife and Karambit (0.5.7.0).** *Knife type* picks a **karambit** (ring spin, reverse spin, ring flurry, pinwheel, backflip, toss and catch, showcase, slash, chaos combo, random) or the butterfly knife below. The butterfly knife is a 3D balisong in a Minecraft arm that wears your skin, shown when your hand is empty. Tricks: **Chaos combo, Flick open, Fan, Showcase, Handle whirl, Rollover, Reverse rollover, Twirl, Gunslinger, Aerial toss, Snap shut** and **Random**. *Trick* is the one used by the trick key, **R** performs it (right click can too), and a second key (unbound, set it in Controls) cycles to the next trick. Settings: size, speed, number of spins, hand, position, trail, blur and sparks. A *Play* button for each trick is on the card. It is modelled on the red slotted balisong of your video.

**Staff HUD.** Now works with **confidence**. Each player collects evidence: a rank word in the name tag or the tab-list team name (strong), a tag worn by someone who is already known to be staff (medium, "same tag as other staff"), creative or spectator mode (weak), a tag only one or two people wear on a busy server (weak). Words like VIP or MVP cancel a rank. Anyone seen as staff stays listed, join and leave messages, the distance, and a red mark for a **spectator close to you**. *Show from confidence* sets the cut-off, *Show reasons* writes why under each name. It still reads only what your Tab list shows.

**Auction Helper.** **Variants** are separate items (Sharpness V is not Sharpness III; price, seller and time left are ignored). A **market memory per server** is kept in `config/zeus-market.json`, decays with a half-life of three days and is used from the first page of the next session. The typical price is a **median**, so a few absurd listings cannot move it, and it says how much evidence is behind it. Deals are **ranked by how much money they save you**, not by percentage, and *Worth at least* hides the tiny ones. The same listing is never raised twice, the pace slows down by itself when the server is slow to turn pages, and *Careful with too-good deals* announces but never buys a listing priced under 12 % of typical.

**Panel.** The **intro film is now stretched by default** (*Panel > Intro film shape*; the old Fit + glow and Fill are still there). The module list and the HUD boxes use the same rounded style.

## What a server accepts

Zeus cannot make a server do something it does not allow. This is how each kind of module behaves.

**Works the same anywhere, because it only changes your screen:** ESP, Block ESP, X-Ray, Hole ESP, Light Overlay, Trajectories, Breadcrumbs, Fullbright, Time Changer, Weather Changer, Chunk Borders, Block Outline, Suspicious Chunks, Waypoints, Zoom, Durability Alert, every Interface module (Watermark, Module List, Info, Armor HUD, Potion HUD, Keystrokes, Target HUD, Radar, Compass, Item Counter).

**Sends normal actions, the server checks them:** Kill Aura, Crystal Aura, Anchor Aura, Auto Clicker, Bow Spam, Bow Aimbot, Auto Totem, Auto Armor, Auto Weapon, Auto Tool, Auto Eat, Auto Fish, Exp Thrower, Chest Swap, Auto Replenish, Surround, Self Trap, Auto Trap, Hole Filler, Auto Web, Self Web, Scaffold, Nuker. They click and place the way you would, so they work as far as the server allows normal clicks.

**Moves you on your side, the server may undo it:** Flight, Speed, High Jump, Step, Low Gravity, Air Jump, Spider, Jesus, Long Jump, Safe Walk, **Parkour** (new), Fast Climb, Reverse Step, Elytra Boost, Anti Void. The server sees where you end up. On a plain server this works; a server with movement checks will pull you back.

**Limited by the server on purpose:**
- **Reach** extends your own aim. Servers refuse block and attack distances much beyond normal (about 5.5 and 4 blocks).
- **Fast Break** breaks blocks faster on your screen, but the server decides when a block is really broken. About 1.4x is accepted; more and the block comes back. "No pause between blocks" is a real gain.
- **Resize** makes you look and feel tiny or huge on your side only. Tight gaps can still push you back.
- **Hitboxes** helps your aim; the server still checks the real distance.
- **No Fall** tells the server you landed before a fall gets long enough to hurt.
- **Anti Knockback** ignores the push the server sends when you are hit. The server still thinks you were pushed, so you may be pulled back a little.

**Removed because they cannot work on your side:** God Mode, Water Breathing, Fire Resistance, Haste, Damage Boost, World Control (time and weather on the server), and the old Quick Actions (game mode, heal, teleport, clear items). The server owns all of those.

### About being "detected"
Zeus does not hide anything. On a server with an anticheat, many of these modules will be noticed and can get you kicked or banned, and most servers forbid them in their rules. I did not build anything to disguise Zeus from an anticheat. Use it where it is allowed (your own worlds, your own server, servers that say yes). The one exception is a tiny convenience in singleplayer: while a module keeps you in the air, Zeus dips you a tenth of a block every second or so, so the game's own "Flying is not enabled on this server" check does not kick you out of your own world. It does nothing on a multiplayer server.

## Crystal Aura and Anchor Aura

**Crystal Aura** works in a loop, one step per tick: if there is no good spot and **Place obsidian** is on, it puts obsidian next to the target; it places an end crystal on the best obsidian or bedrock spot (most estimated damage to the target while your own estimated damage stays under **Maximum self damage**, and **Anti suicide** keeps it from ever killing you); then it breaks crystals that would hurt the target by at least **Minimum damage**. The estimate uses the real explosion rules (distance, line of sight, armor) and ignores enchantments and potions.

Settings: target range, place range, break range, place delay, break delay, minimum damage, maximum self damage, anti suicide, place obsidian, obsidian delay, break only useful crystals, pause while eating, swing arm, targets.

**Anchor Aura** places a respawn anchor next to the target, charges it with glowstone (1 to 4) and sets it off with a slot that does not hold glowstone. It does not run in the Nether. Settings: target range, place range, charges, delay, minimum damage, maximum self damage, anti suicide, swing arm, targets.

You need the items in your hotbar. Zeus does not take them from your inventory for you.

## The interface

- **Panel:** one full-screen window with a sidebar, module rows that open to show their settings, search, an Active page and a Panel page for the look.
- **Windows:** a floating window per category. Left click switches a module, right click opens its settings, click a header to fold a window and drag it to move it. Positions are saved.
- Switch layouts with the button next to the close button, or on the Panel page. Colours, intro (Video, Video once, Lightning, Quick, Off), the main menu switch, thunder sound and messages are on the Panel page too.

### HUD editor
Run `/zeus hud` or open Interface settings → **Open HUD editor**. Drag a widget (it snaps to edges, centre lines and other widgets), scale it with the mouse wheel (0.50x-2.50x), nudge with the arrow keys, Tab to the next widget, **R** reset, **H** hide, **U** undo, **G** grid, **S** snapping, **Esc** done. The floating panel lists every widget with a switch and edits position, scale, opacity and accent colour. Positions are saved under `hudLayout` in `config/zeus.json` and travel with profiles.

### Local web dashboard
Since 0.9.1.0 this is the **Zeus website** (see "What is new in 0.9.1.0"). `/zeus website` (or switching on the **Web Dashboard** module) serves it on `http://127.0.0.1:8765` (this computer only; change the port in the module). On the Settings page paste the access token (click it in chat, or use *Copy the access token*). It shows live status, switches modules, edits every setting, saves presets, has an emergency disable-all, auction-alert settings and a scheduler for delayed module actions. `/zeus website stop` ends it. See 0.8.3.11-0.8.3.17 in the version history for the details and the security notes.

### Server Switch Persistence
Interface → **Server Switch Persistence** chooses what comes back after you change server: Safe only, None, Everything (default) or Customize.

## Building it

Needs Java 21. In this folder:

- Windows: double-click `build.bat`, or run `gradlew.bat build`
- Mac / Linux: `./gradlew build`

The jar is `build/libs/zeus-0.9.8.0.jar` (see "Setup, step by step" above). Settings save to `config/zeus.json`.

### Commands
`/zeus` opens the panel, `/zeus toggle|on|off <module>`, `/zeus list` and `/zeus panic` also work, as do `/zeus hud` (HUD editor), `/zeus tutorial` (replay the tour), `/zeus waypoint add <x> <y> <z> [name]` and `/zeus website|stop|status` (local dashboard, see "The interface"). They are client commands: they are handled by your game and never sent to a server. Every module also has its own unbound key (click the **none** chip on its card).

## Honest limits

- **0.9.7.0 has not been run in a real Minecraft either.** The module costs, Performance Guard, keybind screen, update pop-up, death marker, Twitch lookup and the new knives were compiled and logic-tested against stand-in classes only; the knives were checked in rendered pictures from those stand-ins. The module costs come from Zeus's own timers, not from a profiler, and the Guard's FPS rules were tested only on made-up numbers. The Update checker does nothing until you give it an address. **0.9.6.0 has not been run in a real Minecraft either, and the performance work has not been measured.** I cannot run Minecraft or a profiler here. The changes are structural (idle modules do nothing, lists are cached, outlines and glow are skipped in Light mode, scanners run less often) and should help, but whether you get your frames back depends on which modules you use. The Performance Monitor shows which modules cost the most on your computer. The two PvP bots, Click TP, Skin Change, Atmosphere, Discord Rich Presence, Staff Live, Auto Reconnect and the AH Sniper were only compiled and logic-tested against stand-in classes. Atmosphere is a picture drawn over your screen, not a replaced sky. Skin Change only works for players that are online (in the tab list). Click TP sends a plain position packet, so a server that checks movement can refuse it. Staff Live starts from a list of channels that you should edit. **0.9.5.0 has not been run in a real Minecraft either.** The Boat NoClip / Boat Fly rewrite and the tidied Windows layout were only compiled and logic-tested. **0.9.4.0 has not been run in a real Minecraft either.** The knife motion, the Windows layout, favourites and per-server profiles were checked with the stand-in classes and screenshots only; the profile-per-server hook runs when a world is entered and is wrapped so a failure cannot stop the game. The website profile is local to the browser (no account server), and the module screenshot slots stay empty until media is added.
- **0.9.3.0 has not been run in a real Minecraft either.** The HUD editor changes were checked with screenshots against the stand-in classes (the editor lists 27 widgets and the new cards can be dragged), not in the real game. The website was tested in a headless Chromium on desktop and phone sizes.
- **The website helper is not an AI.** It is a search engine over this site's own content plus rules for common question shapes. It answers what is written down (modules, settings, FAQ, commands, timeline) and says so when it cannot find something. It cannot browse, run code or answer general knowledge. The "thinking" is an animation, not computation time.
- **References are credited from what I know was used.** Meteor Client is listed for the base mod style as you asked; Fabric, Litematica, the fonts and DonutSMP are listed for what they are used for. Correct the list in `site.json` (website) and `ZeusCreditsScreen.java` (in-game) if it is wrong. The root `NOTICE` file still carries the licence attribution that parts of Zeus require.
- A saved empty Discord link in the Web Dashboard settings no longer overrides the new default on the website; the website falls back to https://discord.gg/GcbryFXgcR.
- **0.9.0.0 has not been run in a real Minecraft, and neither has any version before it.** It compiles against hand-written stand-ins for the game's classes (0 errors) and passes my logic tests (160 modules register, settings and persistence round-trip), nothing more. Some mixin targets (`Gui.renderCrosshair`, the player-info handler) are declared with `require = 0` so a wrong name is skipped instead of crashing, but then that feature does nothing. If something fails, send me its Status text, the "Zeus" lines of `logs/latest.log`, or the first red Gradle lines.
- **The estimated base area is a search area, not a location.** It comes from the Goliath grid cell, which is inferred from coordinates (not a server shard id) and can go stale if the server changes its map. Exact coordinates appear only when the player's body is loaded by your client.
- **Staff detection only reads what the server sends.** Ranks, markers and team prefixes are matched against tab text and teams; a server that hides or renames them, or a vanished staff member the server never reports, will not show. A match is a confidence, not proof. The "watching" alert relies on game-mode packets the server chooses to send.

- **0.4.5.1 has not been run in a real Minecraft, and neither have the versions before it.** It compiles and passes my logic tests and interface screenshots against stand-ins for the game, nothing more. The new hooks (the X-Ray light and shade hooks, the light engine hook, No Fall / Anti Hunger packet hooks) target names in 1.21.11 I could not check live; each is written to be skipped if a name is wrong. The Auction Helper in particular has never seen DonutSMP. If a module does nothing, send me its Status text and the "Zeus" lines of `logs/latest.log`. If Gradle errors, send the first red lines.
- **Everything is drawn on the screen, not in the world.** ESP boxes, tracers and markers are projected onto the screen from your field of view, so they can drift a little while you sprint (Freecam and Free Look follow the camera).
- **Cave ESP shows open space, not "caves" as the game defines them.** A large room you dug yourself looks like a cave too. Chunks your game has not loaded are not scanned.

- **0.4.2.0 has not been run in a real Minecraft either.** Every new hook (Freecam camera, No Fall packet, Jesus, Safe Walk, light, Anti Vanish) targets names in the 1.21.11 game that I could only check against stand-ins, and each one is written so that if a name is wrong the hook is skipped and the module tells you so in its Status box instead of crashing. "Every module works" is something I audited and fixed for the ones you named; only you can confirm it in the game. If one does nothing, send me its Status text and the "Zeus" lines of `logs/latest.log`.
- **This version has not been run in a real Minecraft.** I compiled it against my own stand-ins for the game's classes and tested the logic and the interface rendering. A wrong class or method name for 1.21.11 would still stop your Gradle build. I verified the names I was least sure of against the 1.21.11 mappings (the motion and move packets, `ClientLevel.setTimeFromServer`, `MobEffect` display names). If Gradle complains, send me the first few red lines and I will fix them.
- **Mixins that miss are skipped silently.** Anti Knockback, Hitboxes, X-Ray, the glow outline, Morph and Weather Changer use small mixins. If a name is wrong the mixin is skipped and that module does nothing instead of crashing.
- **Weather Changer and Time Changer use the game's client-side time and weather values.** 1.21.11 changed how the clock works, so if the sky does not follow, tell me what you see.
- **X-Ray removes blocks from the chunk meshes through a mixin**, one on the game's chunk view and one on Sodium's / Embeddium's. I have not seen it run in a real game. The Status box on the X-Ray card tells you what happened; if it says the hook did not run, send me that text and the game log. Fullbright and X-Ray ore lighting now use a light hook (with night vision as an optional second method).
- **The title-screen swap is a mixin on the game's screen switch** (with a per-tick check as a backup). If both fail you simply get the normal title screen. The menu does not have the game's language and accessibility buttons or Realms.
- **The menu background was rebuilt from your picture:** the buttons were painted out and the area behind them filled with mist, so there are faint soft patches between the tablets. A clean wide picture without the buttons would look better; drop it in as `assets/zeus/textures/gui/menu/background.png` and rebuild.
- **The film and the menu art are sized for what you sent** (a 1024 x 576 film). A sharper film gives a sharper intro.
- **The menu now shows the real version** (0.4.5.3), the same as the panel.
- **Screen sizes:** the panel and menu are drawn for 16:9. Other shapes work, and very small windows (GUI scale 4 on a small screen) are cramped.
- **Morph is visual only, and only shows where the game draws your own body** (third person and the inventory preview). Mobs that depend on being in water or on special state (squid, dolphins, guardians) are drawn in their resting pose. If a mob cannot be copied, you get a toast and nothing changes.
- **Crystal Aura and Anchor Aura are an estimate.** The damage numbers ignore enchantments and potion effects.
- **ESP 2D boxes and tracers use the game's FOV setting,** so they can drift a little while you sprint.
- **Suspicious Chunks is still a heuristic.** It is stricter now, so a modded or heavily edited structure can slip through, and a very big player base can still be reported as one.
- **Finders only see chunks your game has loaded** (your render distance), and Storage ESP shows block entities as the game reports them.
- Some modules add a hidden attribute modifier named `zeus:...` or a hidden night-vision effect to **your own copy** of the player. They are removed when you switch the module off or leave the world, and Zeus tops them up every few ticks because the server sometimes replaces them.
- Zeus will not work on other Minecraft versions without being rebuilt.

### Not built (and why)
Packet-holding Fake Lag, Player Bypass, block-entity-debug leaks and anti-xray bypasses for Storage / Amethyst ESP (they attack server protections), VanillaSpoof, an Amethyst Bypass or Netherite Finder that sees through anti-xray (declined in 0.9.6.0, the same reason as above), and any reconnect meant to evade bans (Auto Reconnect exists since 0.9.6.0 but only reconnects to the same server after a normal disconnect). Server, chat and network modules (Server Spoof, Spam, Swarm, Notebot and the like), and modules that need deep rendering hooks I cannot test without a real Minecraft (Chams, Blur, Item Physics). Tell me which you want and I will take them next.
